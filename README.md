## 📁 Estrutura de Validação

Para garantir a autenticidade das informações prestadas acima, os documentos comprobatórios estão organizados na seguinte estrutura de pastas:

* **`/academic`**: Diplomas, históricos escolares oficiais e comprovantes de matrícula da UNIVESP.
* **`/data-intelligence`**: Certificados digitais de Power BI, Excel Avançado e ferramentas de Analytics.
* **`/engineering-cloud`**: Comprovantes de conclusão dos módulos de Python (Pandas/NumPy), SQL e infraestrutura AWS.

## 🛠️ Critérios de Auditoria

Cada registro nesta tabela foi validado seguindo três pilares fundamentais:
1. **Idoneidade da Emissora:** Apenas instituições reconhecidas pelo mercado ou pelo MEC (Ministério da Educação).
2. **Rastreabilidade:** Todos os certificados possuem código de verificação hash ou link direto para validação na plataforma de origem.
3. **Aplicação Prática:** Os conhecimentos adquiridos foram diretamente aplicados em projetos reais documentados no meu perfil principal.
